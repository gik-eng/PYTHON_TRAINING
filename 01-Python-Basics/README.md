# Python Basics 🐍

This folder contains beginner-friendly Python exercises.

The focus of these exercises is learning Python syntax,
understanding core programming concepts, and strengthening
problem-solving skills.

---

- Variables
- Data Types
- Conditions
- Loops
- Functions
- Lists
- Dictionaries
- Sets
- Strings
- File Handling
- Basic Algorithms
