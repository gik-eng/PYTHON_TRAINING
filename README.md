# Python Training 🐍

A collection of Python exercises organized by difficulty level.

This repository documents my progress in learning Python through
practical exercises, problem-solving challenges, and small projects.

---

## 📂 Repository Structure

### 🟢 01 - Python Basics

Beginner-level exercises focused on Python fundamentals and
problem-solving skills.

Topics covered:

- Variables and Data Types
- Conditions
- Loops
- Lists and Dictionaries
- Sets
- Strings
- Functions
- File Handling
- Basic Algorithms

### 🟡 02 - Intermediate Python

Intermediate-level exercises focused on more advanced Python
concepts, problem solving, data processing, and Object-Oriented Programming.

Topics covered:

- Functions
- Lambda Functions
- Recursion
- Advanced Data Structures
- Nested Data Structures
- Algorithms
- JSON Processing
- Object-Oriented Programming (OOP)
- itertools
- Data Management

### 🔵 03 - Pandas

Planned section for data manipulation and analysis using Pandas.

Topics will include:

- DataFrames and Series
- Data Cleaning
- Filtering and Sorting
- GroupBy
- Merging and Concatenation
- Pivot Tables
- Crosstab
- Data Analysis
